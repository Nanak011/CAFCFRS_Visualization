Parameter: Choose measure. String, list of values Loss / Victims / ID, shown as Reported loss / Victim reports / Reports.

1. Selected measure (plain CASE; one control switches V1 to V4)

CASE [Choose measure]
WHEN "Loss" THEN SUM([Loss])
WHEN "Victims" THEN SUM([Victims])
WHEN "ID" THEN COUNT([ID])
END

Purpose to record: lets one parameter change the measure in four views.

Used in: V1 bars, V2 colour, V3 bars, V4 bars, Tip trend, labels.

Limitation to state: V5 is not connected to it.


2. Loss per victim 

{ FIXED [Fraud Type] : SUM([Loss]) }
/
{ FIXED [Fraud Type] : SUM([Victims]) }

Purpose: average reported loss per victim report for each fraud type.

Why FIXED: the value stays the same when Solicitation or Year is added to the view.

Test: Investments $82,489 (overall figure $20,135).

Limitation: definition (a); it divides by all victim reports, including the 32,425 victim reports with no loss figure.

Used in: V1 and V5 tooltips.


3. YoY change (table calculation; generated by Tableau's Percent Difference From)

(ZN([Selected measure]) - LOOKUP(ZN([Selected measure]), -1))
/ ABS(LOOKUP(ZN([Selected measure]), -1))

Purpose: percent change of the selected measure from Jan to Sep 2024 to Jan to Sep 2025, per solicitation method.

Must explain: LOOKUP(..., -1) reads the previous Year; ZN turns null into 0; compute-using is set to Year; the 2024 marks have no earlier year, so they show nothing.

Test: Direct call +27.57% on Reported loss; total +15.42%.

Limitation: 2025 is partial and Aug to Sep 2025 may be affected by reporting lag.

Used in: V3 tooltip.
